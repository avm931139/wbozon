# Общая инфраструктура `app`

Пакет содержит общие настройки, подключение к PostgreSQL и SQLAlchemy-модели, которыми пользуются все рабочие модули проекта.

## Файлы

- `config.py` загружает `.env` через `python-dotenv`, преобразует интервалы, флаги и списки задач;
- `db.py` создаёт SQLAlchemy engine, `SessionLocal`, declarative base и контекст `session_scope()`;
- `models.py` содержит ORM-модели WB, Ozon, остатков, дневных срезов, журналов запусков и Telegram-доставок;
- `main.py` вызывает `Base.metadata.create_all()` для локального создания отсутствующих таблиц.

## Правила использования

- Единственный образец настроек — [`.env.example`](../.env.example); реальные токены и `.env` не коммитятся.
- Изменение схемы оформляется Alembic-миграцией. `python -m app.main` не обновляет существующие столбцы и не заменяет `python -m alembic upgrade head`.
- Сервисный код получает сессии через `SessionLocal` или `session_scope()` и сам определяет границу транзакции.
- Новые временные поля следует сохранять timezone-aware; бизнес-дата рассчитывается в настройках соответствующего модуля.

Проверка схемы:

```bash
python -m alembic current
python -m alembic heads
```
