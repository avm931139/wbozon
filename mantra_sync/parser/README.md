# Документация: parser

## Назначение

Папка содержит парсер для работы с внешними веб-ресурсами. На текущий момент основной модуль — [vi_parser.py](vi_parser.py) — предназначен для автоматического открытия страниц сайта vseinstrumenti.ru, обнаружения капчи и ожидания её ручного прохождения.

## Основной файл

- [vi_parser.py](vi_parser.py) — браузерный парсер на базе Playwright с поддержкой работы через реальный профиль Chrome.

## Ключевой класс

- VseinstrumentiParser — класс, который:
  - инициализирует браузер и контекст;
  - открывает страницу по нужному URL;
  - проверяет наличие признаков капчи;
  - ожидает ручное решение капчи пользователем;
  - сохраняет состояние браузера в файл.

## Основные методы

- __init__ — задаёт базовый URL, параметры запуска браузера и хранение состояния.
- __enter__ / __exit__ — обеспечивают использование класса как контекстного менеджера.
- _init_browser — запускает браузер с реальным профилем Chrome и создаёт страницу.
- check_for_captcha — анализирует HTML-код и текст страницы на предмет признаков капчи.
- wait_for_captcha_solve — ждёт, пока пользователь вручную пройдёт проверку, и делает скриншоты.
- check_and_handle_verification — открывает страницу и при необходимости запускает обработку капчи.
- _save_state — сохраняет cookies и текущий URL в файл chrome_state.json.

## Логика работы

1. Создаётся экземпляр класса.
2. Запускается браузер с реальным профилем Chrome.
3. Открывается целевая страница.
4. Если на странице обнаружены признаки капчи, программа сообщает пользователю и ждёт её прохождение.
5. После успешной проверки сохраняется состояние браузера для последующих сессий.

## Зависимости

- Playwright
- Python стандартная библиотека: json, time, logging, re, pathlib, datetime

## Важные замечания

- Модуль рассчитан на ручное прохождение защиты, поэтому в нём предусмотрено ожидание пользователя.
- Для работы требуется локальный профиль Chrome и установленный Playwright.
- В процессе работы создаются файлы скриншотов и состояние браузера: captcha_detected.png, captcha_passed.png, chrome_state.json.

## Когда этот модуль нужен

- для парсинга страниц, защищённых капчей;
- для обхода ручной проверки на сайтах с антибот-защитой;
- для автоматизации действий в браузере с сохранением состояния.
