# Документация: mantra_sync

## Общее назначение

Пакет предназначен для автоматизации работы с маркетплейсами и внутренними сервисами: Wildberries, Ozon, Moysklad, Telegram-уведомлениями и отчетами. Его основная задача — собирать данные, обновлять карточки и остатки, готовить отчеты и отправлять уведомления.

## Архитектура по папкам

- [core](core/) — общие классы, модели и инфраструктурные компоненты, которые используются в нескольких модулях.
- [wb](wb/) — интеграция с Wildberries: карточки товаров, остатки, отчеты, нормализация данных, загрузка в WB.
- [ozon](ozon/) — модуль для получения данных по товарам и интеграции с Ozon.
- [moysklad](moysklad/) — обмен с системой Moysklad.
- [utils](utils/) — вспомогательные утилиты, отчеты и обработка остатков.
- [tools](tools/) — служебные инструменты для работы с остатками, Excel и прогрессом операций.
- [excell](excell/) — экспорт и преобразование табличных данных в Excel.
- [parser](parser/) — парсер данных с внешних ресурсов, в том числе сайтa vseinstrumenti.ru.
- [Report](Report/) — отчеты и вспомогательные инструменты для их формирования.

## Важные файлы

- [main.py](main.py) — точка запуска приложения, планировщик задач и оркестрация регулярных jobs.
- [settings.py](settings.py) — загрузка конфигурации из переменных окружения и .env.
- [bot.py](bot.py) — отправка уведомлений в Telegram.

## Типовые сценарии работы

1. Обновление карточек и остатков товаров на WB.
2. Получение данных с Ozon и их дальнейшая обработка.
3. Подготовка и отправка ежедневных, еженедельных и месячных отчетов.
4. Сбор данных с внешних источников через парсеры и браузерные модули.
