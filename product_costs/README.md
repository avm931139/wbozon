# Себестоимость товаров

`python -m product_costs <файл.xlsx>` импортирует лист `Себестоимость` из подготовленного шаблона.

- строки с пустой себестоимостью пропускаются;
- ID и базовый артикул сверяются с активным `master_products`;
- отрицательные и некорректные значения отклоняются;
- один и тот же файл нельзя импортировать повторно;
- значение и количество сохраняются как историческая оценка на дату из файла.

Таблица `product_cost_records` пока не является партийным учётом. Она хранит исходную себестоимость и текущий остаток, зафиксированный при первичной загрузке. Партийное списание можно добавить отдельно, не меняя эти исходные данные.
