# Ядро проекта

Это отдельный пакет для общей бизнес-логики, конфигурации, работы с БД и сервисного слоя.

## Рекомендуемая структура

- config/ — настройки приложения и переменные окружения
- db/ — модели, сессии и базовые компоненты работы с БД
- domain/ — доменные модели и бизнес-объекты
- services/ — сервисы, где живет основная логика приложения
- utils/ — вспомогательные функции и общие инструменты

## Цель

Собрать в одном месте все, что должно быть переиспользуемым и независимым от конкретного интеграционного модуля.
