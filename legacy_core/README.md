# `legacy_core`

Архивный Python-пакет, оставленный для совместимости с прежней структурой проекта. Сейчас он содержит только `__init__.py`, не импортируется рабочими точками запуска и не участвует в миграциях, фоновых процессах или отчётах.

Актуальная общая инфраструктура находится в [`app`](../app/README.md), доменная логика — в [`wb`](../wb/README.md), [`ozon`](../ozon/README.md), [`inventory_sync`](../inventory_sync/README.md), [`telegram_bot`](../telegram_bot/README.md) и [`healthcheck`](../healthcheck/README.md).

Новый код сюда добавлять не следует. Удалять пакет можно только после отдельной проверки внешних импортов и сценариев развёртывания.
