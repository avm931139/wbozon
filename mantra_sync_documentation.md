# Документация проекта mantra_sync

## 1. Общая идея проекта

Папка mantra_sync — это модуль автоматизации и интеграции данных между несколькими внешними сервисами и внутренними процессами. Основная цель проекта:

- получать данные из маркетплейсов и внешних источников;
- обрабатывать и преобразовывать эти данные;
- обновлять карточки товаров, остатки и отчёты;
- отправлять уведомления в Telegram;
- запускать регулярные задачи по расписанию.

Проект по своей природе близок к ETL/automation-сервису.

## 3. Логика пакета mantra_sync

Проект работает по следующей схеме:

1. Получение данных
   - данные приходят из внешних сервисов: Wildberries, Ozon, Moysklad, парсеры, Excel-файлы.

2. Обработка данных
   - данные проходят через отдельные модули, которые готовят их к дальнейшему использованию.

3. Подготовка отчётов и обновлений
   - из данных формируются отчёты, обновляются карточки товаров, остатки и другие сущности.

4. Уведомления
   - важные события отправляются в Telegram через bot-модуль.

5. Регулярный запуск
   - основные задачи запускаются из main.py как jobs.

То есть логика проекта можно описать как:

сбор данных → обработка → отчёт/обновление → уведомление.

## 4. Описание основных модулей

### 4.1 main.py

Файл [mantra_sync/main.py](mantra_sync/main.py) является главным управляющим модулем.

Он отвечает за:
- запуск задач;
- повторные попытки выполнения функций;
- отправку логов и уведомлений;
- управление расписанием и запуском jobs.

Содержит функции вроде:
- wb_remains_report_job
- stock_report_job
- status_job
- wb_cards_job
- wb_stocks_job
- ozon_products_job
- daily_report_job
- weekly_report_job
- monthly_report_job

Это фактически центральный orchestrator проекта.

### 4.2 settings.py

Файл [mantra_sync/settings.py](mantra_sync/settings.py) хранит конфигурацию приложения.

Он загружает переменные окружения из .env и делает их доступными через класс Config.

Используется для:
- доступа к API ключам;
- подключения к базам данных;
- Telegram-идентификаторов;
- параметров интеграций с Wildberries, Ozon и Moysklad.

### 4.3 bot.py

Файл [mantra_sync/bot.py](mantra_sync/bot.py) отвечает за отправку сообщений в Telegram.

Основные функции:
- отправка простых сообщений;
- отправка сообщений с Markdown;
- безопасная повторная отправка;
- направленная отправка в нужный чат.

### 4.4 core

Папка [mantra_sync/core](mantra_sync/core) — это место для общих классов, моделей и инфраструктурных решений.

Здесь находятся компоненты, которые используются разными частями проекта:
- общие модели;
- базовые классы;
- вспомогательные механизмы;
- части, которые нужно переиспользовать.

### 4.5 wb

Папка [mantra_sync/wb](mantra_sync/wb) — это основной модуль интеграции с Wildberries.

Она, вероятно, отвечает за:
- получение карточек товаров;
- обновление остатков;
- генерацию отчётов;
- нормализацию данных;
- загрузку информации в систему Wildberries.

Сюда входят подпапки:
- analytics — аналитические отчёты;
- data_validator — проверка данных;
- disk_yandex — работа с Яндекс Диском;
- gpt — интеграция с GPT/LLM;
- normalized_wb — нормализация данных WB;
- orders — работа с заказами;
- reports — отчёты;
- updater — обновления;
- wb_upload_card, wb_change_cards — работа с карточками.

### 4.6 ozon

Папка [mantra_sync/ozon](mantra_sync/ozon) содержит интеграцию с Ozon.

Её задача — получать данные по товарам и передавать их дальше в общий процесс обработки.

### 4.7 moysklad

Папка [mantra_sync/moysklad](mantra_sync/moysklad) предназначена для работы с системой Moysklad.

Обычно такие модули используются для обмена данными между внутренней системой и складской/учётной платформой.

### 4.8 max

Папка [mantra_sync/max](mantra_sync/max) связана с сообщениями и логикой Max.

Возможно, это часть, связанная с рассылками, уведомлениями или интеграцией с конкретным каналом/операцией.

### 4.9 parser

Папка [mantra_sync/parser](mantra_sync/parser) предназначена для парсинга внешних данных.

На текущий момент в ней есть модуль [mantra_sync/parser/vi_parser.py](mantra_sync/parser/vi_parser.py), который:
- открывает страницу браузера;
- проверяет наличие капчи;
- ждёт её ручного прохождения;
- сохраняет состояние браузера и cookies.

Это отдельный инструмент для работы с сайтами, которые защищены антибот-защитой.

### 4.10 tools

Папка [mantra_sync/tools](mantra_sync/tools) содержит служебные инструменты.

Они обычно используются для:
- подготовки остатков;
- обработки данных;
- экспортов в Excel;
- вспомогательных операций.

### 4.11 utils

Папка [mantra_sync/utils](mantra_sync/utils) содержит общие утилиты и функции отчётов.

Это место для повторно используемой логики:
- генерация отчётов;
- обработка остатков;
- общие вспомогательные функции.

### 4.12 excell

Папка [mantra_sync/excell](mantra_sync/excell) предназначена для работы с Excel-файлами.

Обычно тут находятся:
- генерация таблиц;
- преобразование данных в Excel;
- экспорт результатов.

### 4.13 Report

Папка [mantra_sync/Report](mantra_sync/Report) используется для отчётности.

Сюда можно относить:
- готовые отчёты;
- шаблоны;
- вспомогательные инструменты обработки данных для отчётов.

## 5. Как проект логически устроен

Проект можно представить как конвейер:

- источник данных;
- обработка и нормализация;
- подготовка отчётов и обновлений;
- уведомление пользователей;
- регулярный запуск по расписанию.

Это делает пакет похожим на автоматизированный сервис синхронизации и мониторинга.

---

## 6. Что особенно важно для понимания проекта

1. Центральная логика находится в [mantra_sync/main.py](mantra_sync/main.py).
2. Конфигурация берётся из [mantra_sync/settings.py](mantra_sync/settings.py).
3. Telegram-уведомления идут через [mantra_sync/bot.py](mantra_sync/bot.py).
4. Wildberries — ключевой интеграционный блок, потому что в папке [mantra_sync/wb](mantra_sync/wb) есть много специфических модулей.
5. Проект содержит смесь рабочих модулей, служебных утилит и экспериментальных файлов.

---

## 7. Что стоит учитывать при дальнейшем развитии

- Лучше разделять “рабочую логику” и “вспомогательные скрипты”.
- Общая логика унаследованного пакета находится в [mantra_sync/core](mantra_sync/core); переносить её в рабочую архитектуру следует только в рамках отдельного рефакторинга.
- Нужно держать документацию и структуру в актуальном состоянии.
- Рекомендуется постепенно выносить интеграции в отдельные сервисы и интерфейсы.

## 8. Короткая версия для ChatGPT

Пакет mantra_sync — это автоматизационный сервис для работы с маркетплейсами и внутренними системами. Он получает данные из Wildberries, Ozon, Moysklad и внешних источников, обрабатывает их, готовит отчёты, обновляет остатки и карточки товаров, а также отправляет уведомления в Telegram. Основная логика запускается из main.py, а интеграционные модули распределены по папкам wb, ozon, moysklad, parser, utils, tools, excell и Report.
